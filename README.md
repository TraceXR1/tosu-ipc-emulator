# IPC Emulator
<div align=center><i>a tool for emulating file-based IPC for osu!lazer tournament overlay</i></div>

This is the simple tool that will receive **osu!lazer** data from memory reader **tosu** and use it to write it into the plain text files in the same format as **osu!tourney** - client for streaming **osu!(stable)** tournaments.

It's meant to be used together with [modified fork of **osu!lazer** tournament overlay](https://github.com/TraceXR1/osu-tclient/releases/latest) and [modified fork of **tosu**](https://github.com/TraceXR1/tosu/releases/latest) memory reader.
